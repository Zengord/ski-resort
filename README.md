# Ski Resort — многостраничный сайт горнолыжного курорта

Многостраничный адаптивный сайт горнолыжного курорта «Такман». Один из самых масштабных проектов в портфолио.

Проект выполнен по готовому макету для практики многостраничной верстки, адаптива и JavaScript-интерактива.

## Возможности

- Адаптивная верстка до 375px
- Многостраничная структура
- Бургер-меню
- Слайдеры
- Попапы
- Интерактивные UI-компоненты
- Использование rem и em единиц
- Отдельная страница 404
- Страница покупки онлайн

## Стек

- HTML5
- CSS3 / SCSS
- JavaScript
- BEM
- Gulp/Webpack
- Swiper
- GitHub Pages

## Что показывает проект

Проект демонстрирует навыки многостраничной адаптивной верстки, организации большого количества страниц, работы с UI-компонентами и публикации сайта на GitHub Pages.
